# 使用说明

EhViewer 是一个为 iOS / macOS 开发的 E-Hentai 网站浏览器，融合了现代 Apple 平台的新特性，并提供多种特色功能。

> 本应用仅用于个人学习与访问公开内容，请遵守当地法律法规与站点条款。

## Profile 系统 *(beta):*

* 新增可以随时切换的`profile`系统，可以在设置顶部进行编辑。
* 每个`profile`间的文件，缓存，记录，设置等内容完全独立。
* 目前使用的方案为切换profile要求使用 `Face ID / Touch ID` 进行身份验证。

## 浏览

1. 卡片是漫画的基本展示和浏览单位。通过卡片，您可以获取漫画的标题、标签、分类、评分和上传日期；艺术家和语言属于可选内容，不一定会在每一个卡片上出现。
2. 如果对某一本漫画感兴趣，点击即可进入详情页。详情页中一般会展示更详细的信息，例如评论、收藏数以及预览图片。
3. 在详情页中可以对漫画进行下载、收藏、评论和评分等操作，也可以直接开始阅读。在线阅读加载速度取决于网络速度和站点情况，可能较慢。
4. 可以在软件设置中自定义卡片的显示内容。

## 搜索和筛选

1. 主页右上角搜索框旁的控件内可以设置高级搜索内容，对浏览和搜索结果的分类、评分等内容进行筛选。
2. 软件内所有搜索框都支持内建的标签搜索功能以及多标签组合搜索功能。只需键入想搜索的类型，预选框内就会显示相关的 Tag；点击后会自动以支持的格式输入。多个 Tag 之间以空格间隔。
3. 在过滤规则中可以设置标签或标签组的屏蔽词，对服务器返回的结果进行本地筛选。注意：启用该选项会导致搜索速度下降，错误的设置可能导致无法搜索。

## 阅读器

1. 阅读器顶部显示标题，右侧的控件可以调整阅读器的个性化设置，例如上下或左右翻页、起始位置等。
2. 长按或右键漫画页面可以将当前页面保存至相册。
3. 底部为进度条控制，拖动可以快速跳转，也可以展开查看预览以精确跳转。
4. iOS / iPadOS 提供全屏阅读功能，点击页面任意位置即可进入或退出全屏阅读。

## 文件

1. iOS 版本：所有下载、导入的画廊或缓存文件都保存在应用沙盒中。设置中导出的文件如果没有手动保存到文件，一般情况下会自动删除。可以在“设置 → 通用 → iPhone 存储空间”中看到 App 占用的全部存储空间。
2. macOS 版本：应用数据大部分保存在 `username/Library/Application Support/Ehviewer` 文件夹中。
3. 保存的文件类型为 `bin` 类型文件，无法直接打开是正常现象。
4. 可以在设置中一键删除全部本地漫画文件。

## 设备间同步

1. 同步使用本地网络进行，双方设备只需要靠近即可，不需要连接同一 Wi-Fi。目前的同步逻辑为取并集。预期速度为 20–80 MB/s；如果速度低于预期，请检查网络环境或尝试使用数据线连接设备。
2. 设备要求：`iOS / iPadOS 18+；macOS 15+`。
3. 启动方式：同步双方设备进入“软件设置 → 数据备份&同步 → 设备间同步”（需要允许本地网络权限）；发起设备点击后，在对方设备上输入显示的 6 位验证码并确认，即可开始自动同步进程。
4. 同步流程：发起同步 → 验证设备 → 导出本地目录并计算差异 → 开始发送或接收 → 双方设备进行本地数据核对 → 完成同步。

## 文件导入导出

1. 文件导入导出功能位于“设置 → 数据备份&同步”内。软件支持两种文件类型：`.ehgallery` 为元数据文件，只包含画廊的标题、标签、阅读进度等信息，文件较小；`.eharchive` 为下载归档，包含元数据以及已下载的图片和视频文件，适合完整备份或迁移本地画廊。
2. 导出时可以选择导出全部画廊，也可以在下载或本地画廊页面进入选择模式，仅导出选中的内容。iOS 版本导出后会打开系统分享面板，可保存至文件、使用隔空投送或发送至其他应用；macOS 版本会要求选择保存位置，需要手动在 Finder 中分享。
3. 导入时请根据文件类型点击对应的导入按钮并选择文件。导入 `.ehgallery` 后只会恢复画廊信息，不会自动下载缺失的图片，因此不会直接显示在本地画廊中；导入 `.eharchive` 后会恢复其中的下载内容。
4. 如果需要从其他版本的软件迁移已下载内容，请将下载目录打包为 ZIP 或 `.eharchive` 文件后选择“导入归档”。

## 下载

1. 在画廊详情页点击“加入下载”即可创建下载任务。任务加入后会显示在下载页面；下载完成的画廊可在“本地”页面离线阅读，未下载完成时也可以阅读已经完成下载的页面。
2. 下载页面可查看任务的下载进度和状态，支持暂停、继续、重新下载、删除单个任务，以及开始全部或暂停全部任务。应用重启后会尝试恢复此前未完成的下载任务。
3. 为了避免服务器压力以及快速消耗 IP 下载配额，下载方式为单本漫画下载。

## 本地画廊

1. 本地页面会展示已有可阅读文件的画廊，使用本地封面和已下载页面，即使没有网络也可以正常进入阅读。未完成下载的画廊会显示当前的下载状态和完成进度。
2. 本地画廊支持标题和标签搜索、分类筛选、列表或卡片展示以及排序。点击画廊可以继续阅读，阅读器会自动记录进度，下次可从上次阅读的位置继续。
3. 进入选择模式后可以全选、批量删除，或将选中的画廊导出为 `.ehgallery` 或 `.eharchive` 文件。删除下载会同时移除本地图片和下载记录，请在确认窗口中仔细检查。
