# 使用说明

EhViewer 是一个面向 iPhone、iPad 和 Mac 的 E-Hentai / ExHentai 画廊浏览、下载与阅读应用。

本说明按照当前应用界面介绍浏览、下载、本地资料库、阅读、设备同步与数据备份。

*部分地区需要使用代理才能正常访问在线内容*

## 浏览与搜索

- 首页、订阅、热门和排行等在线画廊列表支持下拉刷新；紧凑界面的“更多”菜单可进入订阅、热门和排行。
- 顶部搜索框支持画廊关键词、画廊链接和标签。输入时会显示搜索历史与标签候选；多个标签可以组合，已选标签也可以直接移除。
- “高级搜索”可按分类、是否有种子、是否浏览已删除画廊、最低评分及页数范围筛选，并可选择停用站点的语言、上传者或标签过滤器。
- 点击画廊卡片进入详情；点击标签可搜索相同标签，选择“相似画廊”可继续查找相关内容。
- 在“设置 → 过滤规则”中，可以按标题关键词、上传者、精确标签或整个标签组自动隐藏画廊。规则可以单独启用、停用或移除。

## 快速开始

1. 打开应用，在“浏览”页搜索画廊。
2. 点开画廊查看详情，选择“开始阅读”进入阅读器，或选择“加入下载”保存到本机。
3. 已下载内容会出现在“本地”页；进行中的任务及异常状态可在“下载”页管理。
4. 如果需要登录，前往“设置 → 账户与登录”，选择用户名密码、网页登录或 Cookie 登录。

*只有收藏、账户相关内容或 ExHentai 访问需要登录；E-Hentai 的公开内容可以在游客模式下浏览。*

## 漫画下载

在画廊详情页开始下载后，任务会出现在“下载”页面：

- 下载支持排队、暂停、继续、失败重试、开始全部、暂停全部和应用重启后的后台任务恢复。
- 在紧凑布局中，点击工具栏的

  图标打开“下载管理”，可以集中设置任务状态、分类筛选、排序和显示方式；宽屏布局会把这些操作直接放在工具栏。
- 下载页面有列表和卡片两种显示方式：在列表视图中点击
  <img class="inline-app-icon" src="{{ '/assets/icons/square-grid-2x2.svg' | relative_url }}" alt="切换到卡片视图" title="切换到卡片视图">
  切换到卡片视图；在卡片视图中点击
  <img class="inline-app-icon" src="{{ '/assets/icons/list-bullet.svg' | relative_url }}" alt="切换到列表视图" title="切换到列表视图">
  切换回列表视图。
- 可以搜索标题或标签，按全部、进行中、暂停、已完成或异常状态筛选，并按画廊分类进一步筛选。
- 支持按添加时间、标题、完成度、评分或状态排序；本地资料库不提供状态排序。
- 进入选择模式后可以全选和批量移除；单个任务还支持查看详情、暂停/继续、重新下载、设置自定义标签和移除。

## 画廊详情

- 详情页会显示封面、标题、作者或上传者、分类、页数、评分、语言、文件大小、发布时间、标签、评论和页面预览。
- “开始阅读”会优先使用本地已下载页面；下载尚未完成时也可以阅读已有内容。“加入下载”会把画廊放入下载队列。
- 可以收藏、评分、分享或打开相似画廊；工具栏提供“在站点打开”和“刷新”。
- 如果站点和账户提供资源，详情页还会显示种子与站点归档下载入口。
- 预览缩略图优先使用已下载页面；点击任意预览可从该页开始阅读。

## 本地资料库

- “本地”页只显示已有可阅读媒体的画廊，并使用本地封面与页面，离线时也可打开。
- 本地内容支持标题或标签搜索、分类筛选、列表/卡片布局，以及按添加时间、标题、完成度或评分排序。
- 进入选择模式后，可以把选中的画廊分享为 `.ehgallery` 元数据包或包含媒体的 `.eharchive` 归档，也可以批量移除。
- “历史/收藏”页使用分段切换显示最近阅读和本地收藏；历史记录会显示上次阅读页数。
- 在“设置 → 数据与备份”中，可选择“更新全部”或“仅更新缺失信息”，补充已下载画廊的标题、作者、分类、页数、上传日期、缩略图与评分。

## 设备间同步（Beta）

“设置 → 设备间同步”可以在同一局域网内直接合并两台 EhViewer 设备的本地漫画：

1. 两台设备都打开“设备间同步”，并允许系统的本地网络权限。
2. 在一台设备上选择发现的另一台设备，将显示六位验证码。
3. 在另一台设备输入验证码；加密连接建立后，双方再次确认设备。
4. 查看发送与接收的画廊、页面和数据量预览，双方确认后开始同步。
5. 保持两个应用位于前台并连接同一局域网，直到显示“同步完成”。

同步会双向比较本地资料库，只发送双方缺失的已下载画廊元数据和媒体页面，不会广播或传输账号、密码或 Cookie。已完整提交的画廊会在中断后保留；重新连接时会再次比较并补传仍缺少的内容。

## 在 Apple 设备间传输数据

在“设置 → 数据与备份”中：

1. 在原设备选择“导出元数据(.ehgallery)”或“导出归档(.eharchive)”。
2. 使用隔空投送、文件 App 或其他分享方式发送文件。
3. 在新设备选择对应的“导入”操作，并从文件 App 选取文件。

`.ehgallery` 只包含画廊元数据，文件较小，适合迁移列表和详情，但不会携带已下载媒体；

`.eharchive` 还包含下载记录和媒体文件，适合完整迁移本地资料库。也可以在“本地”页只选择一部分画廊后导出。

如果两台设备都能同时运行 EhViewer，优先使用“设备间同步”；需要保留备份、跨网络或稍后导入时使用文件导出。

## 从 Android 设备迁移

请在 Android 设备上找到下载目录，并且按照以下**结构**打包：

```
download.zip
└─download
	├─xxx
	├─xxx
	├─xxx
	└─xxx
```

1. 将归档文件传到 iPhone、iPad 或 Mac，可以使用文件 App、隔空投送或云盘。
2. 在 EhViewer 打开“设置 → 数据与备份 → 导入归档(.eharchive)”。
3. 选取归档并等待导入完成，再到“本地”页面检查结果。

导入时不会覆盖现有的同名下载项；如果归档结构不完整或包含不受支持的文件，应用会报告导入结果。

## 阅读页面

- 点击阅读页面可以显示或隐藏阅读控件；底部进度条和缩略图条可以快速跳页，右上角的“阅读选项”可以调整分页/连续阅读、翻页方向和开始位置。
- 在 iPhone 和 iPad 上还可以设置屏幕旋转、音量键翻页以及音量键方向。
- 阅读页面会保存当前画廊的阅读进度；“设置 → 站点与浏览 → 重置下载内容的阅读进度”可重置所有下载画廊的进度。
- 长按媒体或使用“保存媒体”可以将当前媒体保存到系统照片图库；Mac 端保存到系统下载文件夹。
- Mac 端可以使用方向键或触控板手势翻页。

## 设置与账号

- “站点与浏览”：切换 E-Hentai / ExHentai，控制日文标题与标签翻译，查看或清除缓存，并重置下载内容的阅读进度。清除缓存不会删除下载任务或媒体，但会清除本地收藏和历史记录。
- “账户与登录”：查看游客/登录状态，使用用户名密码、网页登录或 Cookie 登录，也可以清除当前 Cookie。
- “过滤规则”：管理标题、上传者、标签和标签组屏蔽规则。
- “数据与备份”：维护已下载画廊信息，导入或导出 `.ehgallery` 与 `.eharchive`。
- “设备间同步”：在附近设备间安全合并已下载漫画。
- “关于”：打开本使用说明并查看当前应用版本。

## 常见问题

### 为什么首页可以打开，但画廊图片加载失败？

站点可能临时限流、网络不可用或需要有效登录会话。请先检查网络，再尝试刷新；如果使用 ExHentai，请确认账户具备访问权限。

### 我应该导出元数据还是归档？

两台设备在同一局域网并且都能打开 EhViewer 时，使用“设备间同步”双向补齐缺失内容；只需要画廊资料时选择 `.ehgallery`；需要把已下载图片或视频一并迁移或留作备份时选择 `.eharchive`。

### 导入后为什么没有看到画廊？

请先等待导入或同步完成，再打开“本地”页面。`.ehgallery` 不包含媒体，不会让画廊出现在只显示可阅读下载的本地资料库；如果导入的是外部归档，请确认归档内包含应用支持的文件结构。

### 如何清理缓存？

前往“设置 → 站点与浏览 → 清除缓存”。这不会删除下载文件或下载任务，但会清除收藏和历史记录；执行前请确认提示内容。

### 如何反馈问题？

请在 GitHub Issue 中描述设备系统版本、应用版本和可复现步骤。不要在问题中粘贴密码、Cookie 或其他账户凭据。

## 隐私说明

应用数据保存在本机。网络请求用于访问用户选择的站点和下载用户主动请求的内容；设备发现只在“设备间同步”页面打开期间运行，不会广播漫画、账号或 Cookie 信息。
