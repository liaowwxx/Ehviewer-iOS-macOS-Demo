# macOS 原生翻译工作台

从主应用侧边栏底部的「漫画翻译」或「窗口 → 漫画翻译」打开独立窗口，也可以在完整下载的漫画详情页或本地列表批量选择后加入任务。添加漫画不会自动调用模型；在「设置 → 翻译配置」确认源语言、目标语言和各阶段模型后，选中任务并点击「开始翻译」。

侧边栏分为「当前任务」「历史任务」「设置」。当前任务展示待开始与执行中的队列、各阶段进度、最新保存完成的译图、LLM 实际返回内容与运行日志。模型输出在上游请求返回后立即更新；沿用上游请求方式，不额外发起推理请求，也不模拟逐字输出。输出面板可关闭「跟随输出」以阅读前文。已完成、失败、取消与中断的任务保留在历史任务中，可搜索、查看预览或建立新的重试任务。环境安装与翻译配置统一放在设置中。

工作台属于当前 EhViewer 用户。关闭窗口不会停止任务；退出整个 EhViewer 时可以取消退出、等待已开始的队列完成，或者停止后退出。切换用户不会展示另一用户的任务，结果会保留并在回到所属用户后导入。崩溃或停止造成的中断需要手动重试，不会自动重新调用收费服务。

## 环境与模型

首次使用，在「设置 → 环境与模型」选择现有 BallonsTranslator 安装目录。优先使用安装目录内的 `.venv/bin/python`。若缺少环境，选择兼容的 Python 3.10–3.12 作为创建虚拟环境的解释器；不会自动安装系统 Python 或其他系统工具。

先点击「检查环境」，查看缺少的依赖和模型文件，再点击「准备环境与模型」。准备操作复用 BallonsTranslator 的依赖管理和模型下载校验接口，允许写入所选安装的 `.venv`、`data/models` 及工作台私有缓存。它不执行整套 `scripts/install.sh`，不替换源码，也不修改原软件配置。安装或下载中止后，请再次检查实际状态；安装不提供回滚。

普通翻译与设置操作不安装依赖、不隐式下载模型。模型文件和资源引用原有安装，不复制整套环境或权重。仅 macOS 构建包含桥接脚本，iOS/iPadOS 不包含 Python 资源，也不承担模型执行。

## 配置与数据

「翻译设置」提供语言、各阶段模型、模型参数、LLM 服务与模型、上下文、嵌字和输出设置。只有启用对应 LLM 阶段才显示其服务选择，文字、视觉和图像能力分别匹配。常用项直接展示，参数与服务编辑折叠显示。API Key 遮蔽显示，可替换或清除。

模型名称使用配置中的候选列表，也可选择「自定义…」填写服务中的完整模型 ID。「刷新模型列表」读取当前服务的兼容 `/models` 接口（包括 Ollama 的 `/v1/models`），不下载权重或请求推理；刷新仅更新文字翻译模型的候选项，不改变当前选择。视觉和图像模型仍使用各自的候选列表与自定义入口，不根据名称猜测模型能力。服务未启动或不提供列表时，仍可使用已有选项。刷新后需点击「保存设置」持久化候选项。

推理强度和图像细节优先使用服务配置携带的选项；上下文、术语范围、OCR 文字处理、输出格式与字体来源使用选择控件。界面显示中文说明，保存原始枚举值和数字类型。推理强度列表代表配置允许的值，实际支持程度仍取决于服务及模型；未知的已有值和扩展字段会保留。

首次选定安装时复制原配置到工作台，也可以手动导入旧独立应用的预设。工作台保留未知配置字段及模型参数描述。私有配置和日志使用受限权限；这不是系统密钥保险箱，不应分享配置文件。执行时另建不可变快照，并给上游一份可写工作副本，避免上游保存行为改变快照。

任务位于对应用户译本目录的 `NativeWorkstation/` 下。输入是完整下载原图的校验副本，结果须通过整本页数、来源哈希和输出文件校验后才发布。现有译本格式与设备同步保持兼容。

旧独立应用和队列保留，不自动搬迁。新工作台无需旧独立应用同时运行，也不使用固定端口、配对码或原软件管理界面。

## 开发与验证

`EHTranslationMac` 独立模块负责原生窗口、持久化任务、全应用串行调度和进程组管理。宿主仅提供用户身份、完整下载及译本存储。Python 桥接只通过私有管道接收有大小上限的 JSON 控制请求，图片保留在磁盘；上游推理仍使用原有流水线。

桥接脚本由 Xcode 的 `Copy macOS translation bridge` 阶段仅在 `PLATFORM_NAME=macosx` 时复制。未使用 Swift Package 资源束，避免 Xcode 自动向 iOS 包复制 Python 文件。Swift Package 的 Debug 构建从源码位置读取桥接脚本。

针对性验证：

```sh
swift test --filter 'TranslationWorkstationTests|TranslationSettingChoicesTests|TranslationTaskActivityTests'
python3 -B -m unittest discover -s Tests/TranslationAdapterTests -v
xcodebuild -project EhViewer.xcodeproj -scheme EhViewer -sdk macosx CODE_SIGNING_ALLOWED=NO build
xcodebuild -project EhViewer.xcodeproj -scheme EhViewer -sdk iphonesimulator CODE_SIGNING_ALLOWED=NO build
```

Swift 测试覆盖配置保真、记录恢复、能力校验、配置冲突、不完整输入、私有管道及取消、用户隔离与幂等导入。Python 测试覆盖资源引用、源码与配置写保护、准备模式可写边界、协议输入上限、脱敏及失败响应。测试不安装包、下载模型或调用外部翻译服务。
